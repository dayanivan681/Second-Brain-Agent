# Datos sintéticos

**Todo lo que hay en esta carpeta es inventado.** Sirve para construir y probar
el sistema sin el Vault real. Ningún dato describe proyectos, personas ni
decisiones reales. Cada nota lleva `synthetic: true` y el manifiesto también.

La importación real y su evaluación siguen **pendientes** hasta recibir el
paquete de contexto portable (ver `docs/contexto-portable.md`).
